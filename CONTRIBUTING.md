# Contributing to SRM Resume AI

Thank you for your interest in contributing to the **SRM Resume AI** institutional placement platform!

## Development Workflow

### 1. Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher
- **Git**: Configured with your verified GitHub email address

### 2. Local Setup
```bash
# Clone the repository
git clone https://github.com/ktilak12/Ai_resume_filter_srm.git
cd "Ai resume inhouse srm"

# Install dependencies
npm install

# Start local development server
npm run dev
```

### 3. Verification & Code Quality
Before submitting pull requests or pushing commits, make sure your code passes TypeScript type checks and building:
```bash
npm run build
```

---

## Commit Guidelines

Follow standard Conventional Commits formatting:
- `feat:` New features or UI components
- `fix:` Bug fixes and corrections
- `docs:` Documentation updates
- `refactor:` Code restructuring without changing behavior
- `security:` Security hardening and sanitization improvements
- `ci:` Continuous integration and automation workflows
